## 1. 기술 스택 / 아키텍처
- **Electron + electron-vite + React + TypeScript + Zustand + date-fns**
- 저장: **사용자 AppData의 JSON 파일** (`%APPDATA%\nurakzero\nurakzero-data.json`). SQLite 아님(Windows 네이티브 빌드 회피). store.ts에 동일 논리 테이블(categories/user_tasks/settings).
- **창 구조**: 위젯 창 + **대시보드 별도 BrowserWindow**(해시 `#dashboard-left/right`로 역할·슬라이드 방향 구분). 두 창은 `db:changed` 브로드캐스트로 동기화.
- **영문명 = `nurakzero`** (누락=nu-rak. 초기에 nuranzero로 잘못 썼다가 v0.1.0에서 전부 nurakzero로 통일). 시작메뉴 바로가기는 한글 "누락제로".
- Tauri 대신 Electron 채택 이유: PC에 Rust 없음 + `npm run dev` 즉시 실행 요구.

## 2. 구현 완료된 기능
- **메인 위젯**: 이번달 점검표, 지연 우선 정렬, 완료 체크 시 사라짐, ◀▶ 월 이동, 🏠 대시보드, ⚙️ 설정.
- **멀티 업무 위젯(A안)**: 여러 업무 선택 시 **전체를 합쳐서** 표시(지연 최우선), 업무 2개↑면 항목에 **색 태그 + 좌측 색 띠**로 업무 명시. 단일 업무면 태그 없음. (`MonthlyChecklistWidget`의 `WORK_COLORS`, `ChecklistItem`의 `work` prop)
- **대시보드(별도 창)**: 요약(전체/완료/미완료/지연), 월별+수시+완료 목록, 항목 추가/수정/삭제, **카드 드래그로 월 이동**(포인터 기반 — 네이티브 HTML5 드래그는 `user-select:none` 때문에 불가), 드롭다운 월 변경, `CategorySelector` 드롭다운으로 업무 전환.
- **위젯 부가**: 상단 투명도 슬라이더(30~100%, `setOpacity`), 우하단 크기 조절 그립(포인터 캡처), 항상 위/시작 시 실행 토글.
- **온보딩(5단계)**: 시작 → 기본정보(이름·교육청·학교급·기준연도) → 업무선택(별칭 검색, 학교급 필터, 학교급 색태그) → 생성확인(월별 미리보기) → 완료. 창 높이는 내용에 맞춰 자동 조절(최대 800, `ResizeObserver`→`setOnboardingHeight`), 목록은 카드 내부 스크롤(`no-drag` 처리 필수). 교육청은 전북특별자치도교육청만 선택 가능, 나머지 준비중.
- **온보딩 진입 분기**: `settings.onboarded` (`taskStore.init`에서 `?? tasks.length>0` 마이그레이션). `completeOnboarding`/`resetOnboarding` 존재. 자동 시드 없음.

## 3. 템플릿 (핵심 산출물) — ✅ 35/35 완료
- `data/templates/index.json` = 35개 인덱스(templateId·displayTitle·auditCode·schoolLevels·conditionalSchoolLevels·aliases·tags·file·templateStatus). 전부 `ready`.
- `data/templates/<id>.v1.json` = 세부 템플릿(영역당 4~6 task). 로더가 `import.meta.glob('*.v1.json')`로 자동 로드 → **파일만 넣으면 등록 끝**.
- **task 구조**(골든): templateTaskId, title(동사형 ≤40자), shortTitle(글자수 절단 금지), description(실제 점검내용), taskType, cycle, recommendedMonth(1~12 또는 null=수시), priority, checkQuestions[], evidence[](항목별), completionCriteria, sourceBasis("원본 표 NNN: …"), monthReason.
- **골든 샘플 2개**: `privacy_protection.v1.json`, `elementary_student_assessment.v1.json`.
- **월(recommendedMonth)은 매뉴얼 값이 아니라 "누락 방지용 운영 권장값"**. 업무 성격대로 배정(규정·구성=학기초, 교육=상반기, 사안처리=수시, 마감·심의=하반기). 대시보드에서 사용자가 변경 가능.

## 4. 품질 검증기
- `npm run validate:templates` (= `node scripts/validate-templates.mjs`). 특정 id만: `node scripts/validate-templates.mjs <id> <id>`.
- **형식 + 내용 품질** 검사. ERROR 있으면 종료코드 1.
- 잡아내는 것: 보일러플레이트 description(원문 패턴 + 리워드된 상투구=말미 반복), shortTitle 글자수 절단(다음 글자가 글자/숫자일 때만), evidence 복붙(전체/과반 동일), task 15개 초과, 제목 `…`(잘린 원문), "N차 확인" 쓰레기, evidence 괄호 깨짐, 월 편중(monthly 5개↑ & 한 달 60%↑).
- **shortTitle 작성 팁**: title의 앞부분을 그대로 자르지 말 것. 자르려면 단어 경계(다음 글자가 공백/괄호)거나 아예 다른 축약을 쓸 것.
- 현재 결과: **35개 완전통과(ERROR 0, warn 0)**. typecheck·build 통과(번들 ~532kB).

## 6. 실행 / 테스트 / 빌드 명령
```powershell
# 개발 실행
npm run dev
# 데이터 초기화(온보딩부터 다시) — electron 종료 후 삭제
Get-Process -Name electron -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-Item "$env:APPDATA\nurakzero\nurakzero-data.json" -Force
# 검증 / 타입 / 빌드
npm run validate:templates
npm run typecheck
npm run build
# 설치파일
npm run dist   # → release/nurakzero-Setup-<ver>.exe
```
- 데이터 파일 폴더가 가끔 `%APPDATA%\Electron`에도 생길 수 있음(dev 환경). 초기화 시 둘 다 확인.
- 로컬 원본 자료: 루트 `전북…매뉴얼….hwpx`(2.28MB, gitignore), `docs/audit-manual/06-3_privacy_protection.*`(privacy만 있음). 다른 영역 원문은 각 템플릿 `sourceBasis`에 임베드돼 있음(.hwpx 재파싱 거의 불필요. 필요하면 kordoc MCP의 parse_document 사용).
